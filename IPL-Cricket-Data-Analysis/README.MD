# 🏏 IPL Cricket Data Analysis

## 📘 Overview
This project performs a detailed **data analysis of the Indian Premier League (IPL)** from 2008 to 2023.  
Using Python and data visualization libraries, the project uncovers insights about **teams, players, toss trends, venues, and match results**.  

---

## 🎯 Objective
The main goal of this project is to:
- Analyze historical IPL data
- Identify top-performing teams and players
- Explore toss and match-winning relationships
- Visualize trends season-wise and venue-wise

---

## 📂 Dataset
**Dataset Used:** [Kaggle IPL Dataset](https://www.kaggle.com/datasets/manasgarg/ipl)  
Contains two main files:
- `matches.csv` — Match-level data (teams, results, toss, venue, etc.)
- `deliveries.csv` — Ball-by-ball data (batsmen, bowlers, runs, dismissals, etc.)

---

## 🧠 Key Questions Explored
1. Which team has won the most matches in IPL history?  
2. Who are the top batsmen and bowlers?  
3. Does winning the toss impact match results?  
4. Which stadiums have hosted the most matches?  
5. How has IPL evolved season by season?

---

## 🧩 Project Workflow

### 1️⃣ Data Loading & Cleaning
- Imported `matches.csv` and `deliveries.csv`
- Checked for missing values
- Standardized team names  
- Handled null and duplicate entries

### 2️⃣ Exploratory Data Analysis (EDA)
Performed detailed analysis on:
- Most successful teams  
- Top players of the match (MVPs)  
- Toss decision trends  
- Season-wise match counts  
- Venue statistics  

### 3️⃣ Player Analysis
- **Top Run Scorers** – Total runs by batsmen  
- **Top Wicket Takers** – Number of wickets per bowler  
- **Team Performance** – Total runs scored by each team  

### 4️⃣ Data Visualization
Created visual insights using:
- Bar charts for wins, runs, and wickets  
- Line plots for season trends  
- Pie charts for toss decisions  
- Interactive charts using Plotly (optional)

---

## 📈 Key Insights
- 🏆 **Mumbai Indians** are the most successful IPL team.  
- 🎯 Toss winners win the match around **51%** of the time.  
- 💥 **Virat Kohli** and **Chris Gayle** are among the top run scorers.  
- ⚡ **Lasith Malinga** and **Bhuvneshwar Kumar** lead in wickets.  
- 🏟️ **M. Chinnaswamy Stadium** has hosted the most matches.  
- 📅 Fielding first became a more common choice after 2015.
